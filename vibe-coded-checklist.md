# Website "Vibe-Coded" Audit Prompt

Copy-paste this to Claude or ChatGPT along with a screenshot or description of your site:

---

Review my website/design against this checklist of things that make a site look "vibe-coded" (obviously AI-generated) rather than intentionally designed. For each point, tell me if it applies to my site and how to fix it.

**Visual style**
- Harsh or rainbow gradients, purple-and-black / neon color schemes, glowy purple tints
- Drop shadows everywhere, liquid glass effects, radial orbs, dot grids
- Lucide icons, sparkle icons, checkmark bullets on everything
- Soft corner radius applied uniformly to every element
- Gradient text on every headline
- Overly generous spacing between components (feels padded, not composed)
- Zero hierarchy tension — every section has equal visual weight
- Inconsistent shadow/border-radius values across components

**Layout patterns**
- 3-column feature grid used for everything regardless of fit
- Bento grids, fake terminal-window mockups
- Colored left stripe on cards, bright left/top bars on dark backgrounds
- Exactly 3 feature cards in a row, exactly 3 pricing tiers
- Horizontal scroll bars appearing through menus or on mobile
- Excessive full-bleed sections stacked with no visual rhythm
- Centered-everything layouts with no asymmetry

**Typography**
- Inter / Geist / Space Grotesk for body + Fraunces for "quirky" headers (default AI pairing)
- IBM Plex Mono / JetBrains Mono used decoratively everywhere
- Hard-to-read, tiny text
- Interpuncts (·) used as decorative separators

**Copy/content**
- Overused em dashes
- "It's not X, it's Y" sentence construction
- AI overexplainer text ("Not sure what to do? Click here. Does X. Does Y.")
- Subcopy under titles that just restates the title
- Fake testimonials
- No real product demos, leftover placeholder text

**Interaction/motion**
- Unnecessary hover animations, animated arrows
- Features added with no "does the user actually need this" gate
- Loading skeletons missing, or added just for show

**Trust/legitimacy gaps**
- No Terms of Service, no privacy policy
- No empty-state page, no 404 page
- No error/success messages on forms
- No real contact info, no clickable email/phone number

**Technical/SEO**
- Horizontal scroll on mobile / x-axis not locked
- Missing meta descriptions, missing favicon, generic page titles
- Uncompressed images
- Broken links, no mobile menu
- Not tested on an actual mobile device, mobile overflow bugs
- Inconsistent alt text, keywords, schema markup
- Forms with no submission redundancy or error handling
- Anchor links instead of real templated pages with clear CTAs
- Project images not organized into clickable galleries/lightboxes

---

Go through this list section by section, flag every issue you find, and give specific fixes rather than general advice.
